# Security policy

Please do not disclose vulnerabilities in public issues. Use GitHub private vulnerability reporting for this repository. Include affected version, reproducible impact, and a minimal proof of concept without real credentials or prompt data.

The maintainers will acknowledge a report within seven days, coordinate remediation and disclosure, and publish supported-version information with the first release. Rotate any credential accidentally shared in a report before submission.

The project never needs production prompts, responses, API keys, cookies, access tokens, or database exports to investigate a report.
