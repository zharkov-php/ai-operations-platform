# Roadmap

The project proceeds through independently validated and committed phases. A phase is complete only when its implemented scope, documentation, tests, lint/static analysis, build validation, diff review, secret check, commit, and push attempt are reported.

## Foundation

0. Architecture and requirements documentation.
1. Go, Next.js, and Expo monorepo foundation.
2. API runtime, dependencies, health, metrics, and migrations.
3. Organization-scoped authentication and authorization.
4. Projects and workloads.
5. Model catalog, effective pricing, and decimal-safe cost.
6. Redacted, scoped, idempotent LLM-call ingestion.
7. Bounded tenant analytics.
8. Transparent rule-based classifications and recommendations.

## Product surfaces

9. Indexable public Next.js website and SEO.
10. Public cost, prompt, and routing tools.
11. Authenticated analytics dashboard.
12. Recommendation review workflow.
13. Evaluation datasets and runs.
14. Local-model economics simulation.
15. Guarded controlled experiments and verified savings.
16. Budgets and alerts.
17. Expo operational companion.
18. Notification abstraction and safe delivery.

## Hardening and release

19. Observability and operational resilience.
20. CI/CD and security automation.
21. Deterministic end-to-end demo.
22. Documentation and portfolio audit.
23. v0.1.0 release preparation, annotated tag, and verified remote push.

Detailed acceptance criteria are maintained in the product implementation prompt and will be reflected in phase reports as work proceeds. The roadmap does not imply that phases after Phase 0 are implemented.
