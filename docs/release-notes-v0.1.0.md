# AI Operations Platform v0.1.0

The first portfolio release delivers the complete AI Execution Advisor journey: ingest redacted execution metadata, calculate observed decimal-safe cost, inspect evidence-based recommendations, evaluate candidates, run guarded experiments, and distinguish estimated from verified savings.

Start the deterministic environment with `make demo`. It provides five representative workloads and prints local sign-in and documentation URLs. No provider credentials are required.

This release is suitable for portfolio demonstration and local engineering evaluation. It is not a hosted production service, does not proxy real production traffic, and uses clearly illustrative pricing.
